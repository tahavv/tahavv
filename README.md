This repository is both my GitHub profile README and the source of [taha-ayari.vercel.app](https://taha-ayari.vercel.app), a Nuxt 3 site deployed on Vercel.

```bash
npm install

```

The contact form sends mail through the [Sender](https://www.sender.net) transactional API. Copy `.env.example` to `.env` for local work and set the same variables in Vercel.
